# Security Policy

## Reporting a vulnerability

Please do not publish exploit details, payment signatures, wallet authorization payloads, or other sensitive material in a public issue.

For this public x402 service, use the repository security page as the contact surface:

https://github.com/P00NSMASHER/permitplate-nyc/security

If a private reporting channel is not available there, open a minimal issue that says only that you have a security report and need a private contact path. Do not include exploit steps, credentials, payment payloads, or other sensitive details in the public issue.

## Scope

Security reports relevant to PA Entity Lookup x402 include payment bypasses, duplicate-settlement risks, payment-state confusion, forged settlement receipts, unintended data exposure, unsafe input handling, and discovery metadata that could redirect payments to the wrong asset, network, or wallet.
