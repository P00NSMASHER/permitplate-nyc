+# PA Entity Lookup x402 — Full Agent Reference
+
+Canonical origin: https://pa-entity-x402.floot.app
+
+## Purpose
+
+Resolve Pennsylvania business names into structured Pennsylvania Department of State registration records for machine-to-machine company identity, legal-entity enrichment, vendor/customer verification, due diligence, and lead enrichment.
+
+## Paid endpoints
+
+### $0.001 best match
+
+GET https://pa-entity-x402.floot.app/_api/pa-entity-one?q=NAME
+
+Returns at most one highest-ranked Pennsylvania legal-entity result using the same enriched result schema.
+
+### $0.005 enriched search
+
+GET https://pa-entity-x402.floot.app/_api/pa-business?q=NAME&limit=10
+
+Returns up to 25 ranked entity candidates.
+
+Prices apply per successful settled lookup.
+Protocol: x402 v2.
+Network: Base mainnet (eip155:8453).
+Asset: Base USDC.
+Payment recipient: 0x708f7b52b56eafd7fc1de65fc7752ed732914021.
+
+## Input contract
+
+q:
+- required string
+- 2-120 characters
+- Pennsylvania company name or distinctive legal-name fragment
+
+limit:
+- accepted only by /_api/pa-business
+- optional integer
+- 1-25
+- default 10
+
+/_api/pa-entity-one is fixed at one returned match.
+
+The service removes SQL wildcard characters from the search term, rejects control-only/too-short queries, uses strict integer parsing for limit, and will not contact the payment facilitator for an invalid paid retry.
+
+## Matching strategy
+
+1. Case-insensitive starts-with query against business_name.
+2. Rank normalized legal-name matches first, ignoring common suffixes such as LLC or Inc.
+3. Run a broader contains query only when the starts-with result set does not fill the requested limit.
+4. Deduplicate by filing number before returning results.
+
+This avoids whole-record search false positives such as a company matching only because its address contains a brand name.
+
+## Entity fields
+
+Each result preserves:
+
+- businessName
+- filingNumber
+- registrationType
+- address1
+- address2
+- city
+- state
+- zip
+- county
+
+and adds:
+
+- creationDate
+- countyCode
+- principals[]
+
+Each principals entry contains:
+- role
+- firstName
+- middleName
+- lastName
+
+Exact duplicate principal rows are removed. Missing names are not inferred.
+
+The top-level enrichment.principals field is "complete" when principal enrichment succeeded and "unavailable" if the secondary enrichment query failed while the base registry result remained deliverable.
+
+## Payment-state behavior
+
+Unpaid request:
+- HTTP 402
+- PAYMENT-REQUIRED present
+- no-store
+
+Invalid PAYMENT-SIGNATURE:
+- HTTP 402
+- machine-readable invalid-payment reason
+- never misreported as a verifier outage
+

+# PA Entity Lookup x402
+
+Use this tool for Pennsylvania business-registry lookup, company identity resolution, legal-entity enrichment, vendor/customer verification, due diligence, filing-number lookup, registration-type lookup, creation-date lookup, and registered-address/county confirmation.
+
+Choose one of two paid endpoints:
+
+Low-cost best match:
+
+GET https://pa-entity-x402.floot.app/_api/pa-entity-one?q=NAME
+
+Price: $0.001 USDC per successful settled call. Returns at most one highest-ranked entity.
+
+Multi-result enriched search:
+
+GET https://pa-entity-x402.floot.app/_api/pa-business?q=NAME&limit=10
+
+Price: $0.005 USDC per successful settled call. Returns up to 25 ranked candidates.
+Protocol: x402 v2.
+Network: Base mainnet (eip155:8453).
+
+## Input
+
+- q: required on both endpoints; company name or distinctive name fragment, 2-120 characters.
+- limit: only on /_api/pa-business; optional integer 1-25, default 10.
+
+## Matching
+
+The service queries the Pennsylvania business_name field case-insensitively.
+It uses a fast starts-with search first and a broader contains search only when needed.
+Normalized legal-name matches are ranked before broader matches.
+
+## Output
+
+Each result preserves the original fields:
+
+- businessName
+- filingNumber
+- registrationType
+- address1
+- address2
+- city
+- state
+- zip
+- county
+
+and adds:
+
+- creationDate
+- countyCode
+- principals[] with source-published role, firstName, middleName, lastName
+
+The response also reports whether principal enrichment completed.
+
+## Limitations
+
+The Pennsylvania source does not by itself establish current good standing, sanctions status, legal authority, risk score, or a legitimacy verdict. Principal/officer rows are source-published records and should not be treated as independent proof of current management authority.
+
+## Payment recovery
+
+If settlement is unresolved, retry the same request with the same PAYMENT-SIGNATURE. Do not generate a new authorization merely because the service returned settlement_pending or a transient 503.
